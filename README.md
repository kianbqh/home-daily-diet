# 今天想吃啥

> 先把家里的菜记下来，再一起决定今天吃什么。

一个给家庭使用的微信小程序：把做过的家常菜放进自己的菜品库，家人从已有菜品里提交想吃的菜，再一起确认当天的菜单。吃完以后，还可以继续补充这道菜的照片和制作记录。

## 为什么做它

家里其实做过很多好吃的菜，但过一段时间就容易想不起来；每天反复问“今天吃什么”，也很容易重新回到那几道老菜。

“今天想吃啥”想做的是一个简单的家庭记忆库：

- 记住家里做过的菜。
- 让每个人都能提交自己想吃的菜。
- 把当天的选择留在一个地方。
- 慢慢积累属于这个家的味道。

## 怎么使用

1. 记录一道家里的菜，菜名必填，图片可选。
2. 家人从菜品库里选择今天想吃的菜。
3. 汇总候选，确认当天菜单，并分享给家人。
4. 吃完后继续补充制作记录，让菜品库越来越完整。

核心顺序是：先记录菜品，再从菜品库里选择。

## 当前版本可以做什么

- 创建家庭空间，邀请其他家人加入。
- 建立家庭自己的菜品库。
- 记录菜名和可选的一张照片。
- 为同一道菜追加后续制作记录。
- 家庭成员分别提交当天想吃的菜。
- 确认当天菜单并查看选择结果。
- CloudBase 可用时跨设备同步。
- CloudBase 暂时不可用时，仍保留本地使用能力。

### 当前版本暂不包含

- 内置聊天。
- 公开菜谱社区。
- 自动推荐和自动提醒。
- 语音识别。
- 大语言模型解析菜谱。

## 项目状态

当前版本：0.1.3

本版本主要完善了 CloudBase 初始化失败时的处理：

- 家庭页不会因为云端初始化失败而空白。
- 家庭名称、称呼和菜品记录仍可在本地继续使用。
- 页面会显示正在连接、已连接、连接失败或本地模式。
- 修复首次保存只有事件、没有家庭主文档时的读取问题。
- 自动修复旧版本遗留的不完整本地状态。
- 修复真机打包时运行配置文件被忽略，导致应用初始化未完成的问题。
- 即使设备本地存储初始化异常，也会保留可用的本地家庭空间。
- 修复微信小程序不支持直接 require JSON 配置文件，导致应用启动失败的问题。

### CloudBase 配置注意事项

1. CloudBase 环境需要绑定当前微信小程序账号，并在微信开发者工具中使用对应环境。
2. 数据库中需要创建 family_states 和 family_states_events 两个集合。
3. 开发联调时，集合权限需要允许小程序完成读取、写入和新增事件。
4. 云存储不需要预先创建 family-meals/ 目录，首次上传图片时会自动产生路径。
5. 当前版本是小程序客户端直连 CloudBase，不能严格证明访问者属于某个家庭；正式扩大使用范围前，应把家庭状态读写迁移到校验 OpenID 和家庭成员关系的云函数中。
