# 0.3.0 GitHub 发布与仓库主页设计

**状态：** 已确认

**日期：** 2026-08-19

**目标仓库：** `kianbqh/home-daily-diet`

## 1. 目标

把当前已经完成的基础功能与第二阶段家庭菜谱能力整理为 `0.3.0`，并将 GitHub 仓库首页从偏部署记录的说明页，调整为普通家庭用户先读得懂、开发者随后能运行和部署的项目主页。

本次发布包含当前工作分支中已完成且通过测试的代码、版本号、README 和 GitHub 仓库元数据。不会虚构截图、在线体验地址、备案状态或生产级稳定性，也不会把任何 API Key 写入仓库。

## 2. 公开定位

产品名称继续使用“今天想吃啥”。核心定位固定为：

> 记录家里做过的菜，一起决定今天吃什么。

GitHub Description 使用：

> 记录家里做过的菜，一起决定今天吃什么。支持家庭共享、点菜、评价、制作记录和语音整理菜谱的微信小程序。

README 采用“用户优先、开发信息后置”的结构，不使用夸张广告词。

## 3. README 信息结构

README 按以下顺序重写：

1. **标题、定位与版本**
   - 标题“今天想吃啥”。
   - 一句话说明这是家庭菜品记忆与共同选餐小程序。
   - 明确当前仓库版本为 `0.3.0`。

2. **它解决什么问题**
   - 家里做过的好菜容易被忘记。
   - 每天重复询问“吃什么”却难以临时想起。
   - 先积累家庭菜品库，再从已有菜品中点菜。

3. **核心能力**
   - 家庭空间、短邀请码与多成员同步。
   - 菜品库、图片、分类标签、制作记录和回收站。
   - 家人共同点菜、确认菜单与针对每次制作的评价。
   - 手动或普通话语音记录做法，AI 只整理为待确认草稿。
   - 家庭主菜谱、本次做法和只读历史版本。

4. **典型使用流程**
   - 记录菜品。
   - 家人从菜品库选择想吃的菜。
   - 确认一餐菜单。
   - 做完后追加照片、制作记录、评价或菜谱经验。

5. **隐私与产品边界**
   - 家庭数据不做公开社区和公开搜索。
   - 不提供内置聊天。
   - 语音仅支持普通话；AI 不得自动覆盖正式菜谱。
   - 项目仍需要部署者自行完成 CloudBase、微信隐私与备案配置。

6. **开发与部署**
   - 简述微信小程序原生框架、CloudBase、腾讯云 ASR 与 TokenHub。
   - 保留本地测试命令和必要的 CloudBase 资源清单。
   - 复杂索引、环境变量、预算和双账号验收改为链接到现有部署文档，不在首页重复大段细节。

7. **参与项目**
   - 欢迎通过 Issue 提交使用反馈与建议。
   - 不承诺尚未建立的公开演示、CI、许可证或贡献流程。

## 4. 版本与发布策略

- 根目录 `package.json` 版本更新为 `0.3.0`。
- README 中所有“当前版本”统一为 `0.3.0`，删除把第二阶段描述为尚未实现的旧文案。
